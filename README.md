# .github

The organisation profile and the default community files of DeltaV Modding.

- `profile/README.md` - the page on github.com/DeltaV-Modding
- `CONTRIBUTING.md`, `SECURITY.md`, `SUPPORT.md`, `CODE_OF_CONDUCT.md` - used by every repository that has none of its own
- `.github/ISSUE_TEMPLATE/`, `.github/pull_request_template.md` - the default issue and pull request forms
