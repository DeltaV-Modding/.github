# Code of conduct

We want our issues, pull requests and Discord to be a friendly place for everyone.

- Be respectful. Criticise code and ideas, not people.
- No harassment, insults, discrimination or personal attacks, in public or in private messages.
- No cheats or griefing tools for multiplayer, and no requests for them.
- Help newcomers; everyone started somewhere.

Maintainers may remove comments, close issues or block people who break these rules. Report a problem to the maintainers on
Discord or by mail to modding@buildercraft.net.
