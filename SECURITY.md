# Security policy

If you find a security problem in one of our projects - for example a way to make the launcher, the injector or the mod site run code
or install files the user did not choose - **please do not open a public issue.**

Report it privately instead:

- through GitHub's **Report a vulnerability** button on the repository's Security tab, or
- by mail to modding@buildercraft.net.

Say what is affected, how to reproduce it, and what an attacker could do. We answer within a few days and tell you when a fix is
released. Thank you for helping keep the players safe.
