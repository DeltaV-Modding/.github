We build mods, tools and loaders, mostly for Stormworks: Build and Rescue and Minecraft, and we like to find out how
things work under the hood.

## 🚂 Stormworks

| Project | What it is |
|---|---|
| [**DeltaLoader**](https://github.com/DeltaV-Modding/DeltaLoader) | The C++ SDK for native Stormworks mods: hooks, the game's functions by name, rendering, physics, network, mod settings, a UI toolkit. [Documentation](https://deltav-modding.github.io/DeltaLoader/) |
| [**DeltaLauncher**](https://stormworks-tools.com/download) | Install mods with one click, switch them on and off, start the game with them. Updates itself. |
| [**DeltaLoader Server**](https://stormworks-tools.com/server) | The same mods on a dedicated server, for Windows and Linux. Players and server compare their mods when someone joins. |
| [**stormworks-tools.com**](https://stormworks-tools.com/) | The mod site: mods, islands, versions, reviews and the downloads above. |

Everything Stormworks-specific is built from our own observations of a purchased copy of the game. No game code or assets
are shipped.
